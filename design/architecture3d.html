System architecture

Four layers, top to bottom. A shopper request (blue arrows) goes from the browser to the Express function on Vercel, through the Prisma repository layer, into Supabase Postgres. Test and uptime tools sit on the right.

Where tests hook in

  1. Playwright drives the browser, calls /api directly and checks Postgres for @db tests.
  2. Scoped reset clears only your session namespace, so parallel workers never collide.
  3. Test hooks (chaos headers, seeded bugs) need TEST_TOOLS_ENABLED and a test key.
  4. cron-job.org hits /api/health/db every 10 minutes so the free database never pauses.
  5. GitHub Actions runs CI on every PR and an hourly production smoke check.
