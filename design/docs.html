POST/api/v1/cart/items

Add an item to the cart

Adds a product variant to the signed-in user's cart, or increases its quantity if it is already there. Stock is reserved for 15 minutes.

openapi.json Postman collection

Request body

FieldTypeRules
productId requiredstringAn existing SKU
variant stringRequired when the product has variants
quantity requiredinteger1 to 5

Example request

curl -X POST "$ORVILO_URL/api/v1/cart/items" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"productId":"ELE-0031","variant":"tactile-graphite","quantity":1}'

Example response

{
  "cartId": "c_8f21",
  "items": [
    { "productId": "ELE-0031", "quantity": 1,
      "unitPrice": 89.00 }
  ],
  "subtotal": 89.00,
  "reservedUntil": "2026-10-28T14:27:00Z"
}

Errors

  • 400 VALIDATION_ERROR — quantity is not an integer from 1 to 5
  • 401 UNAUTHENTICATED — missing or expired token
  • 409 OUT_OF_STOCK — not enough stock to reserve
  • 429 RATE_LIMITED — see the Retry-After header
