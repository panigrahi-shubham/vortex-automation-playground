What is and is not included

- Every screen layout, colour, illustration, icon and 3D diagram was drawn
  for this project. No code, images or icons were copied from any other
  store, theme, template or UI kit.
- Product images are plain colour tiles, so there are no stock photos.
- "Orvilo", "Orvi", "Keyhaus", the products, people, emails, addresses and
  order numbers are made up. The card numbers are public payment-testing
  numbers that only work in test modes.
- Tool names in the architecture diagram (Vercel, Supabase, Prisma,
  Playwright, GitHub Actions, cron-job.org) are used only to say what the
  stack runs on. No logos are included.
- General layout patterns (a filter sidebar, a stepped checkout, a chat
  layout) are common conventions that anyone may use. Similar patterns
  appear in open-source stores such as Next.js Commerce, Medusa, Saleor and
  Shopify Dawn, but nothing was taken from them.
