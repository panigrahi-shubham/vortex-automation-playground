Terms of Service

Last updated: 1 January 2026

ShopLab is a practice store for learning test automation. No real products are sold, no real payments are taken and no real emails are sent.

1. Test data

All data is held in memory and is wiped whenever the server restarts or POST /api/reset is called.

2. Fair use

Please don't load-test the public demo instance. Run ShopLab locally for performance experiments.

3. Seeded bugs

Some behaviour is intentionally wrong when bug mode is on. Finding those bugs is the point.
