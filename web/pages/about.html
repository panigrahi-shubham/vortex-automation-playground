About Vortex

Built to Break. Designed to Test.

Vortex Automation Playground is a place to learn and practice software testing using a realistic simulated store. Explore journeys, find issues and build your own automation framework at your own pace.

What you can practice

  • Browse products, manage a cart and complete simulated checkout.
  • Explore accounts, orders and API interactions.
  • Use the UI Lab to work with frames, shadow DOM, dialogs and other browser interactions.

Payments and store activity are simulated. Some exercises and test controls depend on the environment; see the testing guide for current availability.

The Vortex projects

This playground is the website project. Vortex Web Recorder, the Android application and Android Recorder are separate projects.
