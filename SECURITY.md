# Security

Report a suspected vulnerability privately through the repository's [security advisory form](https://github.com/panigrahi-shubham/vortex-automation-playground/security/advisories/new). If the form is unavailable, contact the maintainer privately. Include the affected version, steps to reproduce, and the result you expected. Use a local instance and omit credentials or personal data.

Vortex QA is a practice application. The legacy mode contains deliberate defects, simulated payments, and test data. Run it locally for experiments. The production storefront uses the PostgreSQL API and its server-side access checks.

For deployment boundaries and local verification, see [Setup](docs/SETUP.md) and [Production boundaries](docs/PRODUCTION_BOUNDARIES.md).
